# Determinant, Rank and Inverse

## 一、行列式（Determinant）

### 1.1 定义

对于 $n \times n$ 方阵 $A$，行列式 $\det(A)$ 是一个标量，描述矩阵变换对空间的**体积缩放效应**。

**二阶：**

$$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$

**三阶（萨吕法则）：**

$$\det\begin{pmatrix} a & b & c \\ d & e & f \\ g & h & i \end{pmatrix} = a(ei-fh) - b(di-fg) + c(dh-eg)$$

### 1.2 几何意义

| 维度 | 几何解释 |
|:---|:---|
| 2D | 单位正方形变换后平行四边形的**有向面积** |
| 3D | 单位立方体变换后平行六面体的**有向体积** |

**符号含义：**

- $\det(A) > 0$：保持空间定向（右手系）
- $\det(A) < 0$：翻转空间定向（镜像反射）
- $\det(A) = 0$：空间被压缩降维（面积/体积坍缩为0）

### 1.3 Eigen API

```cpp
Eigen::MatrixXd m;
m.setRandom(3, 3);
double det = m.determinant();  // 计算行列式
```

## 二、秩（Rank）

### 2.1 定义

矩阵 $A$ 的秩是其**线性无关的行（或列）的最大个数**。

等价表述：

- 行空间的维度 = 列空间的维度
- 矩阵中非零奇异值的个数
- 最高阶非零子式的阶数

### 2.2 几何意义

秩表示矩阵线性变换后**像空间的维度**。

```
输入空间 ℝ³                    输出空间

    ●                          ●
   /|\    [矩阵A: rank=2]     /      (被压扁成平面)
  / | \   ──────────────→    /
 ●──┼──●                     ●────●
    |

三维空间 → 二维平面（信息丢失一维）
```

| 秩的情况 | 含义 |
|:---|:---|
| rank(A) = n（满秩） | 变换保持维度，不压缩空间 |
| rank(A) < n（降秩） | 空间被压缩到更低维子空间 |
| rank(A) = 1 | 所有向量映射到同一条直线 |
| rank(A) = 0 | 零矩阵，所有向量映射到原点 |

### 2.3 与行列式的关系

- 方阵满秩 ⟺ det(A) ≠ 0
- 方阵降秩 ⟺ det(A) = 0

### 2.4 Eigen API

```cpp
Eigen::MatrixXd m;
m.setRandom(3, 3);

Eigen::FullPivLU<Eigen::MatrixXd> lu(m);
lu.setThreshold(1e-10);        // 浮点误差容差阈值
std::cout << "Rank: " << lu.rank() << "\n";
```

> `FullPivLU` 通过全主元 LU 分解计算秩。设置阈值是工程实践，用于处理浮点精度问题。

## 三、矩阵的逆（Inverse）

### 3.1 定义

对于 $n \times n$ 方阵 $A$，若存在 $A^{-1}$ 满足：

$$AA^{-1} = A^{-1}A = I$$

则称 $A^{-1}$ 为 $A$ 的逆矩阵，$A$ 称为**可逆矩阵**（非奇异矩阵）。

**可逆的等价条件：**

- det(A) ≠ 0
- rank(A) = n（满秩）
- 所有特征值非零
- 列向量线性无关

### 3.2 几何意义

逆矩阵是**原变换的"撤销"操作**。

```
原始变换 A                    逆变换 A⁻¹
    ●───●                                 ●───●
    │   │   ──[A]──→  ┌───┐  ──[A⁻¹]──→   │   │
    └───┘             └───┘               └───┘

正方形 → 平行四边形 → 正方形（恢复原状）
```

**不可逆的情况：** 变换压缩了维度，信息丢失，无法还原。

```
三维 → 二维投影（不可逆）
    ●
   /|\    [投影到xy平面]       ●────●
  / | \   ──────────────→     │    │
 ●──┼──●                      └────┘
    |
   (z信息丢失，无法从二维恢复三维)
```

### 3.3 对角矩阵的逆

对角矩阵的逆有特殊性质：只需将对角线元素取倒数。

$$
D = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 3 \end{bmatrix}, \quad
D^{-1} = \begin{bmatrix} 1 & 0 & 0 \\ 0 & \frac{1}{2} & 0 \\ 0 & 0 & \frac{1}{3} \end{bmatrix}
$$

### 3.4 Eigen API

```cpp
Eigen::DiagonalMatrix<double, 3> m1;
m1.diagonal() << 1, 2, 3;

Eigen::Matrix3d m2 = m1.toDenseMatrix();  // 转为密集矩阵

Eigen::FullPivLU<Eigen::Matrix3d> lu(m2);
lu.setThreshold(1e-10);

if (lu.isInvertible())              // ✅ 先验证可逆性（工程必需）
{
    Eigen::Matrix3d m3 = m2.inverse();  // 求逆
    std::cout << "m2*m3 = \n" << m2 * m3 << "\n";  // 验证：应接近单位矩阵
}
```

## 四、三者关系总结

```
┌─────────────────────────────────────────────────────────────┐
│                     方阵 A (n×n)                             │
└─────────────────────────────────────────────────────────────┘
                              │
            ┌─────────────────┼─────────────────┐
            ▼                 ▼                 ▼
       ┌─────────┐      ┌─────────┐      ┌─────────┐
       │ det(A)  │      │ rank(A) │      │  A⁻¹    │
       └─────────┘      └─────────┘      └─────────┘
            │                 │                 │
            ▼                 ▼                 ▼
       体积缩放因子      像空间的维度       逆变换是否存在
            │                 │                 │
            └─────────────────┴─────────────────┘
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
              det(A) ≠ 0            det(A) = 0
              rank(A) = n           rank(A) < n
              A⁻¹ 存在              A⁻¹ 不存在
              （可逆/非奇异）        （不可逆/奇异）
```

## 五、核心要点速查

| 概念 | 数学本质 | 几何意义 | Eigen API |
|:---|:---|:---|:---|
| **行列式** | 标量值 | 体积缩放比例、定向 | `.determinant()` |
| **秩** | 线性无关行/列数 | 变换后空间的维度 | `FullPivLU::rank()` |
| **逆矩阵** | 满足 AA⁻¹=I 的矩阵 | 原变换的撤销操作 | `.inverse()` |

## 六、工程注意事项

1. **浮点精度**：判断秩或可逆性时，必须设置容差阈值 `setThreshold(1e-10)`
2. **先判断再求逆**：求逆前先用 `isInvertible()` 验证，避免数值错误
3. **对角矩阵优先**：对角矩阵求逆只需取倒数，可用 `DiagonalMatrix` 高效存储
4. **验证结果**：求逆后通过 A·A⁻¹ ≈ I 验证正确性
